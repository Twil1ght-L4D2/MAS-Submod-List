# Monika After Story (MAS) Curated Submod Database

This repository serves as the official, safe-checked database and manifest for the **[Your Launcher Name]** launcher. 

### 🛡️ Safety & Quality Guarantee
Every submod included in this database undergoes manual inspection prior to being added. We enforce strict moderation standards to ensure:
- **0% NSFW / Lewd Content:** All dialogue, outfits, sprites, and assets are vetted for safe viewing.
- **Code Integrity:** All `.rpy` / `.rpym` scripts are reviewed to prevent malicious behavior or unwanted background actions.
- **SHA-256 Checksum Verification:** Download archives are hash-verified to prevent unauthorized modifications or broken updates.

### 📦 Features for Launcher Integration
- **Dynamic Manifest (`submods.json`):** Standardized, machine-readable JSON structure detailing submod categories, release download links, and install directories.
- **One-Click Installation Support:** Structured folder paths mapped directly to `game/Submods/`.
- **Regular Maintenance:** Active updates when authors issue safe upstream releases.
